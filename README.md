# CertiProof – Desktop Identity & Document Verification App

CertiProof is a lightweight, secure desktop application built to eliminate document forgery. It provides a localized environment to verify the absolute authenticity of academic, professional, or institutional certificates using cryptographic integrity checking.

## 🚀 Key Features
* **Cryptographic Fingerprinting:** Generates secure SHA-256 hashes of uploaded document files.
* **Instant Discrepancy Matching:** Cross-references the document's live hash against official, verified records to instantly detect tampering.
* **Modular Interface:** Features a clean, desktop graphical user interface (GUI) built for seamless drag-and-drop document uploads.

## 🛠️ Tech Stack
* **Language:** Python
* **GUI Framework:** Tkinter / PyQt
* **Security:** `hashlib`, Cryptographic utilities
